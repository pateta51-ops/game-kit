# engine-core: step causes (K79, opt-in)

`inCause(ctx, ruleCause('R-12') | effectCause(recordId, printedLineId), () => ...)` stamps `cause` on every event emitted inside it that has none (innermost wins); a game that never calls it emits what it did. `causeProblems(events, { counts, known? })` lists the counted (number-changing) events with no cause, an empty id or line, or one `known` refuses; replay-cli's golden check runs it when the game module exports `causes`. Source: middle-earth-player `cause.ts`. Only events emitted while `run` executes get the cause: tasks queued inside it with `ctx.then` run later without it, so a handler that defers work wraps that task's own handler in `inCause` too. An event that sets `cause` itself keeps it; `cause: undefined` keeps the active one.
