# K362 post-build notes

(a) performance: potracer is pure Python; a 480x480 mask traces in about a second, a large logo (8x upscale) takes minutes. `retrace` renders one raster per fill colour. `symmetrise` is O(pixels x group size).

(b) implicit state: none beyond `bw`'s `source.sha256` stamp in the output folder (skip when current). `proof` fidelity assumes the SVG keeps the crop's framing (`--no-trim`); a trimmed SVG gives a low IoU.

(c) kit candidates: none beyond this change. Left in the games: per-icon rules (colour rules, erase boxes, value-number overlays), ring/frame fitting of the ER map icons, the Jarl logo layer logic, vtracer colour tracing (k-means plus potrace replaces it).
