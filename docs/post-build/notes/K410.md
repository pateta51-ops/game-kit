# K410 energy and transfers tuner

(a) performance: plasma orb and drift cloud redraw a full canvas every frame while shown (stopped on replay or effect change). Every slider input replays once per animation frame.

(b) implicit state: `vals` (touched sliders; empty = Kit default), the running canvas loop `stop`, and `data-custom`/`data-route`/`data-token` flags on the stage. The "Kit default" is "unset": the code block lists only touched values.

(c) kit candidates: none. The orb and drift cloud drawing loops are small; a shared "canvas effect harness" would only pay off with a third consumer.
