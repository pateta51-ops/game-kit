# K246 token-bag post-build notes

(a) Performance: the rest bag renders a frame only when ready or resized; a draw runs one rAF loop with a 30 fps watch. three.js is a dynamic import (Rest.tsx, Draw.tsx). Faces are rasterised once per session and size; the scene allocates a 1024 px shadow map during a draw.
(b) Implicit state: the session fallback is a module-level store (`getFallback`/`setFallback`) shared by all bags; the draw overlay hides the dock canvas through inline `visibility`; `Draw` phase (loading, playing, done, back) is local state.
(c) Kit candidates: none beyond this component.
