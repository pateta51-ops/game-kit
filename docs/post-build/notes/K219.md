# K219 card-pile notes

(a) performance: the fan measures the DOM once on open; every fanned card is a `will-change: transform` layer (as the source); `Pile` recomputes the model and marks each render (pile sizes are small).
(b) implicit state: `mode` (rest/fan/gather) is explicit in `logic.ts step`; `landed` and `wasPicking` are flags in `Pile.tsx` (opening animation finished, a pick was open); the phone sheet is a separate boolean beside `mode`.
(c) kit candidates: none beyond this component (the modal-focus ring could serve other overlays).
