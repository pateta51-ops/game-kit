# K402 post-build notes

(a) Performance: one extra `setTimeout` per card when `onCardStart` is given (none otherwise); no polling.

(b) Implicit state: `dealFrom` keeps a per-call set of start timers and animations so `signal` can end only its own flight; `finishDeckMotions` flushes (fires) pending starts, abort drops them. `withViewTransition` is one flight, so `onCardStart` is called once with index 0 and the optional `id`.

(c) Kit candidates: none.
