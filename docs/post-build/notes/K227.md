# K227 post-build notes

(a) Performance: pull now re-extracts every component of the game's kit each time (it always moves the whole kit); a few seconds at most. `outdated` runs a handful of git commands.

(b) Implicit state: the lock has two shapes (new: top-level `ref`/`commit`; old: `ref` per component). `check`, `state`, plancheck and `outdated` accept both; remove the old branch once no game has an old lock. `kit.new` and `kit.old` are temporary folders next to `kit/` during a pull.

(c) Kit candidates: none.
