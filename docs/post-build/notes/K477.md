# K477 post-build notes

(a) Performance: the YuE2 pipeline is reloaded for every seed (one child per take); the worker logs that time per take. Cost grows with tries; the trade is that a take is no longer thrown away by the demucs memory check.

(b) Implicit state: the first-generation GPU check runs in the first child only (a `first` flag in the take file). `minAvailDemucsGiB` (3) is an estimate, not measured; the parent's peak line now reports the largest child.

(c) Kit candidates: none.
