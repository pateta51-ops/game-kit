# K223 card-zones: post-build notes

(a) Performance: `locate` scans every zone (as Imperium and Unstoppable do); `moveCard` and `canSee` call it, so a game with thousands of cards moving many per action may want an index. `viewOf` rebuilds every zone's list per call; a UI that calls it per render should memoise on the state.
(b) Implicit state: `shown` (revealed cards) lives inside each zone and is cleared by a move or shuffle; what "the opponent remembers a card it saw" means is left to the game.
(c) Kit candidates: none beyond the component itself.
