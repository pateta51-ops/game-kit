# K396 notes
(a) performance: the top view samples 241 frames at start to size its canvas and uploads one back texture; the side view writes count x 8 transforms per frame (160 at 20 cards). p95 16.8 ms at 4x CPU throttle on a 390 px phone, same as the riffle-preview build.
(b) implicit state: two maps say a deck is riffling (riffle-surface active, ui riffling) plus the riffles set that finishDeckMotions walks; the deck visibility is saved and restored by animatePile.
(c) kit candidates: animatePile (a rAF frame loop over a hidden pile with finish) could drive other pile motions.
