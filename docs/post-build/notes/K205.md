# K205 post-build notes

- Performance: the kit test generates the game and runs its whole `npm run check` (about 12 s locally; 16 sim games on two workers take under a second). The scaffold test (K204) does a similar run; together they are the slowest kit tests.
- Implicit state: the template app's game store (`src/ui/store.ts`) settles the other seat's prompts in a loop inside `answer`, `fresh` and `load`; no named state for "the other seat is thinking" (it answers synchronously).
- Kit candidates: none. The scaffold's `vitest.config.ts` now also runs `tests/**/*.test.tsx` (it skipped React tests before).
- The kit test pulls components at `git rev-parse HEAD`: an uncommitted change to a component is not under test locally; commit first.
