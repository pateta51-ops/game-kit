# K382 post-build notes

(a) Performance: each step calls view() and options() once and appends one line to decisions.jsonl; the cached system prompt is resent every call (billed at cache-read price). The pre-call cost ceiling is a character estimate, deliberately high.

(b) Implicit state: none beyond the run loop's `stop` value, which names every way a run ends (done, max-decisions, max-usd, finding).

(c) Kit candidates: none further; the component itself is the candidate.
