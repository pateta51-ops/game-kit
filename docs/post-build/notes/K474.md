# K474 post-build notes

(a) Performance: `heavy run --mem` runs one extra `systemd-run ... true` probe per capped run (about 0.1 s). The queue step is O(leases) as before.

(b) Implicit state: the cap is only set when `queue` is not false; with `queue: false` YuE2 runs uncapped (documented). A take killed by the cap is recognised from exit code 137 in the worker's error text, not from a cgroup event. `memGiB` (14) and `minAvailGiB` (6) are chosen from the 20 GB WSL total, not measured; the worker prints its peak host RSS (demucs excluded) so they can be tuned.

(c) Kit candidates: none.
