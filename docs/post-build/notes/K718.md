# K718 post-build notes

(a) performance: each scan is traced once (at most 512 px on its long side) and cached by URL; each mesh is built once per scan and size; a token redraws only when its attributes or size change, with one gl.readPixels-style copy into its own 2D canvas per draw (the dice layer does the same). Many tokens turning every frame would be one copy each per frame.
(b) implicit state: `data-p3-drawn` on the token element says the solid is drawn and hides the flat chip; it is removed on context loss and on stop.
(c) kit candidates: `traceAlpha`, `simplify`, `triangulate` (outline from alpha, ear clipping) could serve scan-ingest or a hit-test of an irregular token.
