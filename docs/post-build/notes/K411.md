# K411 post-build notes
(a) performance: the page mounts 12 stages at once (four small React roots, one RAF loop per playing part); board-viewport re-renders on every slider move. Fine on a phone-width page; none heavy.
(b) implicit state: each part's play keeps its own cancel function and timers in the mount closure (no shared state name); the modal stage toggles `hidden` and `inert` by hand because the kit Modal portals to the body and cannot be contained.
(c) kit candidates: the generic part builder (stage, Kit default, sliders, code and Copy from one definition) could become a shared tuner helper; nothing else.
