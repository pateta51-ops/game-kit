heavy-queue catches runs that skip the queue: the server sweeps WSL every 20 s for heavy test processes (vitest, playwright, vite build, tsc -b, pytest, chromium headless) whose environment lacks `HEAVY_HELD=1` and that are not under a GitHub runner (`Runner.Worker` ancestor). It renices each to 19 (once), and records it on the status page and in `/status` as `unqueued: [{pid, cmd, cwd, firstSeen}]` plus a `bypass.log` (cwd names the game or worktree). It never kills them. `heavy status` prints them. The README says so.
