audio-gen: an optional per-cue `capLength` (seconds) that `tail.maxLengthX` multiplies instead of `length`; it never enters the raw file name, so `--reuse-raw` finds the same takes. `tools.py specs` writes it from the cue sheet's length when the spec's generate length differs. Cues without it behave as in v0.225.0.
