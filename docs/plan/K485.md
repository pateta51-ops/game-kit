audio-gen YuE2: sung lyrics, checked by speech-to-text. Today every YuE2 cue is instrumental: lyrics are always [Instrumental], the Vocal voice is silenced, and the demucs vocal gate fails any vocal share.
- New cue field `lyrics` (string, YuE section tags such as [verse] / [chorus]). With it, the cue keeps the Vocal voice and passes the text to YuE2; without it, nothing changes (instrumental, today's gate).
- For a cue with lyrics, the vocal gate is replaced by a lyrics check: after the take, transcribe the demucs vocal stem with a local Whisper model (faster-whisper, CUDA only, no CPU fallback; in its own step after the YuE2 child exits, through the heavy queue with a memory cap like demucs) and compute the word error rate against the written lyrics (lower case, punctuation and section tags stripped). Fail the take when it is above `lyricsMaxWer` (cue option, default chosen from a measured sample, README says how), or when the vocal stem is near silent; the failed take's reason names the heard words and the WER, and the next try runs as today.
- install.sh installs the model and package (into an existing venv if it fits, else its own); `check` fails a lyrics cue when the model is missing, with the install command.
- README "Rules for agents": how to write lyrics, that the check needs the model, what a lyrics fail means.
- Tests: the WER normaliser; lyrics cue keeps Vocal and skips the instrumental gate; a fake transcript over and under the limit; instrumental cues unchanged.
