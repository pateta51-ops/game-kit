card-harness `cardsCheckMain`: an optional baseline file of known problem lines. Lines in it are allowed; a new line fails, and so does a baseline line no longer found (the file only shrinks); `--write-baseline` writes today's lines with a comment header. Without a baseline, the output is unchanged. Ported from Unstoppable's check.ts.
