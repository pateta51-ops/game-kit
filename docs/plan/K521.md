content-pack `dossierRow`: a thin helper beside `loadText` for dossier card CSVs (component_id, deck, name, type, quantity, text, icons_on_card, art_front, art_back, plus extras). A base zod row with a per-game column map (game columns renamed onto the row's fields, the rest kept), a joined printed text from a list of text columns, an icon lexer `parseIcons(text)` for `{code}` and `{code:N}` checked against the game's icon table, a check that `icons_on_card` (a count) matches the printed icons when filled, and `expand(records)` giving one id per physical copy (`base#1..N`), skipping non-deck rows. Not a general CSV-to-pack loader: each game still writes its kinds.
