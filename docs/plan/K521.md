content-pack `dossierRow`: a thin helper beside `loadText` for dossier card CSVs. `card-parts` `parseIconText` grows by addition to return the value of `{code:N}`, and `dossierRow` calls it (no second icon reader). New: that value, a check that the `icons_on_card` count matches the printed icons when filled, a per-game column map (game columns renamed onto the row's fields, the rest kept), a joined printed text from a list of text columns, and `expand(records)` giving one id per physical copy (`base#1..N`), skipping non-deck rows. Not a general CSV-to-pack loader: each game still writes its kinds.
