engine-core `enumerateAnswers`: for an ordered prompt (the player orders N picks) it lists every order, not each set once in option order; and it takes an optional `valid(state, answer)` so a game drops answers its engine would refuse (an illegal pick set). Unordered prompts and callers without `valid` get the same list as before. Interfaces grow by addition.
