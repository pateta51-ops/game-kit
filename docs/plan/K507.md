card-language: an op table for games that keep their own engine. One row per op holds `{fields, run, text}`: the fields the op takes, a `run` hook typed on the game's own state through an EnginePort-style context, and the sentence the card shows, built with card-language's text generator; a validator checks a card's ops against the table (unknown op, missing or extra field). Ported from Unstoppable's opTable.ts; examples use invented text, no game's names.
