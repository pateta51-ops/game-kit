heavy-queue gives WSL's file cache back to Windows: after a job ends (at most every `HEAVY_DROP_EVERY_MS`), when `Cached` exceeds `HEAVY_DROP_CACHE_GB` (default 6, 0 = off) it drops clean cache through `sudo -n`; status shows the cache size and the last drop.
