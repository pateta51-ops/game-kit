token-flights: 3D token flight, ported from Warp's Edge src/ui/tokens3d (motion.ts, timing.ts): a 3D-object flight (a path plus a pose for a three.js Object3D) next to the 2D `move`/`arc-move`; `token-flights` gains 3D flick, discard and draw paths with their timings (2D arc default unchanged); helpers `endRect(el)` (an element's resting rect after its running animations) and `isSoftwareGl()` (so a game can turn 3D tokens off on software WebGL). Uses effect-library's host-scene option (K438) when present. Interfaces grow by addition.
